Lab 11: Longitudinal Analysis 1

In this Lab, you will analyze the “mood_sim” dataset, which contains simulated Ecological Momentary Assessment (EMA) data from 100 participants collected over a 14-day study period. At Level 1, the dataset includes each participant’s momentary mood score (mood, continuous outcome), whether they had exercised recently (workout, categorical: 0 = No, 1 = Yes), and the hours of sleep they got the night before (sleep, continuous predictor). At Level 2, it includes each participant’s identifier (subject, discrete).

Understanding Time in this Lab

Because participants were pinged at random times, the intervals between surveys are highly unequal. We have provided two different ways of representing time in this dataset to handle these complexities:

  1. studyday: This is a whole number (1 to 14) representing which day of the study the participant is on. Even if a participant answered at 8:00 AM on Day 1 and 8:00 PM on Day 2, the “distance” in studyday is treated as exactly 1 unit. We use this for our Discrete AR(1) model, which assumes observations happen in an equal-interval sequence.
  2. studyday_frac: This is a decimal timestamp (e.g., 1.33, 2.80) representing the exact hour of the study. We use this for our Spatial Exponential model, which allows the model to calculate the true distance between observations to handle the continuous-time problem.

If we tried to use the messy studyday_frac decimals in a discrete AR(1) model, the software would treat every unique second as a separate category. This often leads to convergence errors because the model cannot find enough data to fill thousands of empty time slots.

1. Data Prep (1.0 pts)

Download the “mood_sim.csv” dataset from Canvas, add it to your project folder, and read it into R as a tibble called dat_raw. Use the code below to prepare the data for analysis. In your Quarto file, annotate this code by adding comments explaining what each step does.

dat_l2 <- 
  dat_raw |>
  # COMMENT
  summarize(
    .by = subject,
    sleep_b = mean(sleep, na.rm = TRUE)
  ) |> 
  # COMMENT
  mutate(sleep_bc = center(sleep_b))

dat <- 
  dat_raw |>
  # COMMENT
  left_join(dat_l2, by = "subject") |> 
  mutate(
    # COMMENT
    sleep_w = sleep - sleep_b,
    # COMMENT
    workout = factor(workout)
  ) |> 
  # COMMENT
  arrange(subject, studyday_frac) |> 
  mutate(
    # COMMENT
    time_d = factor(studyday),
    # COMMENT
    time_c = numFactor(studyday_frac)
  )

2. Base Model (1.0 pts)

Fit a multilevel model to dat using glmmTMB(). Predict mood from the fixed effects of the categorical Level 1 predictor (workout), the centered trait continuous predictor (sleep_bc), and the state continuous predictor (sleep_w).

Include random intercepts per subject, as well as random slopes for both Level 1 predictors (workout and sleep_w). Print the model parameters.

3. Cross-Level Interaction & Plotting (1.0 pts)

Expand on your model from Part 2 by adding an interaction between the categorical state predictor and the centered trait predictor (workout * sleep_bc). We are testing whether a person’s average sleep moderates the mood benefits of a daily workout.

Print the parameter summary for this new model. Then, use the easystats package to visualize this interaction.

4. Discrete Autocorrelation (1.0 pts)

Using your model from Part 3, account for the sequence of observations by adding a discrete AR(1) structure to your random effects. Make sure you use the discrete time_d variable you created during data prep.

Computation Warning: Models with autocorrelation structures and random slopes are mathematically complex. It is completely normal for the models from Parts 4 and 5 to take 30 to 60 seconds to run. Please be patient while the optimizer works!

Compare this new Part 4 model to the Part 3 model using a Likelihood Ratio Test (LRT). Did adding the discrete autocorrelation structure improve model fit? (Note: We use an LRT here because the two models are nested).

5. Spatial Exponential Autocorrelation (1.0 pts)

Because participants occasionally missed days, the time intervals in this study are not perfectly equally spaced. Fit a final model that swaps out the discrete AR(1) structure for a Spatial Exponential structure (exp()). Make sure you use the continuous time_c variable you created during data prep.

Compare this Part 5 model to the Part 4 model using AIC and BIC. Which autocorrelation approach provides a better fit for this data? (Note: We must use AIC/BIC here instead of an LRT because the AR1 and Exponential models are not nested).

6. Final Model Interpretation (1.0 pts)

Looking at the parameter tables for your preferred model from Part 5, interpret all of the fixed effects (the intercept, the main effects of workout, state sleep, and trait sleep, and the interaction). What does this model tell us about the factors that influence daily mood?
