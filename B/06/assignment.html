Lab 06: Random Intercepts

Setup and Data Preparation

First, load the necessary packages (e.g., tidyverse, lme4, and easystats) and your data. You will be using the “smiling.csv” dataset (available on Canvas) for the entirety of this lab. It is a subset of real data from Campbell, Girard, McDuff, & Rosengren (2025). Be sure to format sex and nation as factors. Also, create a new variable called gdp by applying the standardize() function to the gdp_percap_ppp variable. This will prevent model convergence warnings and make the slope easier to interpret.

Part I: Null Models

For this section, we will partition the variance in smiling behavior across different nations.

Question 1: Fitting the Empty Model

Empty models, or null models, are models with no predictor variables. They are an excellent first step when learning multilevel modeling (MLM).

  • 1a. Fit a null model predicting smile with a random intercept for nation. You will need to specify the generic formula y ~ 1 + (1 | cluster) using the lmer() function. Assign this model to an object.
  • 1b. Use the model_parameters() function to view your results. In your own words, report and interpret the fixed intercept and the random intercept standard deviation.

Question 2: Intraclass Correlation Coefficient (ICC)

We will continue using null models to estimate ICCs.

  • 2a. Calculate the unconditional ICC for your null model. You can extract the variances manually to calculate this, or you can use the convenience functions from the easystats performance package.
  • 2b. Interpret the ICC in the context of this dataset. Specifically, what percentage of the variance in smiling is between nations, and what percentage is within nations?

Part II: Level-2 Predictors

For this section, we will add a Level-2 predictor to our model. Because a nation’s GDP (gdp_percap_ppp, an indicator of national wealth) is measured at the cluster level, it has no variance within a cluster. Therefore, it has a single, fixed effect across the entire population.

Question 3: Fitting an L2 Predictor

By adding predictor variables to MLMs, we can try to explain or predict variance partitions.

  • 3a. Fit a model predicting smile with a fixed effect for gdp and a random intercept for nation. Use the generic formula y ~ 1 + z + (1 | cluster) as your guide.
  • 3b. Interpret the fixed intercept and the fixed slope of gdp. What does the intercept represent in this context (where the standardized GDP is zero), and what is the expected change in a nation’s average smiling score for a 1 standard deviation increase in GDP? Is this slope statistically significant?

Question 4: The Cost of Ignoring Clustering

It can be tempting to use a simpler model, but ignoring the clustered nature of your data comes with costs.

  • 4a. Fit a standard linear model (OLS) predicting smile from gdp using the lm() function. Then, use compare_parameters(..., select = "se") to compare the standard errors of the OLS model and your MLM from Question 3a. Briefly explain why the standard errors differ and the danger of ignoring clustering.
  • 4b. Visualize the marginal effect of gdp on smile using your multilevel model from Question 3a. Extract the relation using estimate_relation() and plot it.

Part III: Level-1 Predictors

For this final section, we will test a Level-1 predictor. Level-1 predictors try to explain variance within clusters. We will assume the effect of our L1 predictor is identical across all clusters.

Question 5: Fitting an L1 Predictor

  • 5a. Fit a model predicting smile with a fixed slope for sex and a random intercept for nation. Use the generic formula y ~ 1 + x + (1 | cluster) as your guide. Assign this model to an object.
  • 5b. Interpret the fixed slope of the sex variable. What is the expected difference in smiling scores for this predictor, and is it statistically significant?

Question 6: Visualizing Fixed Slopes

  • 6a. Derive the cluster deviations to see how each nation deviates from the fixed intercept. You can extract these estimates using estimate_grouplevel(fit, type = "random").
  • 6b. Visualize the marginal effect of sex on smile using your MLM by extracting the relation with estimate_relation() and plotting it. Because we only estimated a random intercept and a fixed slope, what assumption does this model make about the effect of sex across different nations?
